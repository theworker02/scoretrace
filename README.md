# scoretrace

Score digests and trace fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/scoretrace/

## Install / run

```bash
git clone https://github.com/theworker02/scoretrace.git
cd scoretrace
node src/cli.js
node --test
```
